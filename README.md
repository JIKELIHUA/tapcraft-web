## 🌐 1-Click Zero-Cost Deployment to Vercel

This repository has zero backend dependencies and deploys directly to **Vercel** or **Cloudflare Pages** for **$0 / month forever**:

### Option A: Via GitHub (Recommended)
1. Create a new private or public GitHub repository named `tapcraft-web`.
2. Push this directory to your GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/tapcraft-web.git
   git branch -M main
   git push -u origin main
   ```
3. Log in to [Vercel.com](https://vercel.com) using your GitHub account.
4. Click **"Add New Project"** -> Select `tapcraft-web` -> Click **"Deploy"**.
5. Your site is instantly live with free global CDN and automatic SSL!

### Option B: Via Vercel CLI
```bash
npx vercel
```
